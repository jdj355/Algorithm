### 문제 요약

0 이상의 두 정수가 **문자열** `a`, `b`로 주어질 때, `a` + `b`의 값을 문자열로 return 하는 solution 함수를 작성

### 접근 방법

- 두 문자열을 **일의 자리부터** 한 자리씩 더한다. 합이 10 이상이면 올림(carry)을 다음 자리에 넘긴다. (세로셈과 같은 방식)

- while문은 **a의 자리가 남았거나(i≥0), b의 자리가 남았거나(j≥0), 올림이 남았으면(carry>0)** 반복한다. 셋 중 하나라도 참이면 계속 돈다.

- 각 자리의 **문자를 숫자로 변환**한다(`charAt - '0'`). 자리가 없으면 0으로 처리한다.

- `sum = x + y + carry` → 두 자리 숫자와 **이전 자리에서 넘어온 올림**을 더한다.

- `sum % 10` → 일의 자리를 `sb.append`로 붙인다.

- `sum / 10` → 십의 자리를 carry에 저장해서 **다음 자리 계산에 더한다.**

- `i--`, `j--`로 한 칸 왼쪽으로 이동한다.

- 일의 자리부터 쌓였으니 마지막에 `reverse()`로 뒤집어서 반환한다.

### 막혔던 점 / 배운 점

- a와 b가 동시에 반복문에서 돌아야하는데 그 코드를 짜는 부분이 처음에 헷갈렸음→ while문으로 해결

- 문자열을 charAt으로 뽑아서 문자열을 숫자로 바꾸는 과정 ‘0’을 쓰면  간편함

- sb.append(sum % 10) → 나머지로 일의 자리를 붙이고 sum/10으로 10을 넘어간 +1을 처리를 해준 코드 로직을 배웠음.

- 일의자리 수부터 append를 했기에 reverse() 해주기

### 코드

```java

class Solution {
	public String solution(String a, String b) {
		StringBuilder sb = new StringBuilder();
		int i = a.length() - 1; // 이게 맨 뒷자리 인덱스이니까 여기부터 시작하겠다는 소리임
		int j = b.length() - 1; // 이것도 마찬가지임
		int carry = 0; // 10이상이되면 +1 되는 숫자를 담는 변수임

		while (i >= 0 || j >= 0 || carry > 0) { // a나 b에 숫자가 남아있거나, 올릴 숫자가 남아있으면 계속 진행
			int x = (i >= 0) ? a.charAt(i) - '0' : 0; // 숫자가 남아있으면 그 문자를 숫자로 변경하고 숫자가 남아있지 않으면 0으로
			int y = (j >= 0) ? b.charAt(j) - '0' : 0;

			int sum = x + y + carry; // 두값을 더한다 + 이전의 넘어온 +1의 값
			sb.append(sum%10); // 10으로 나눈 나머지값을 sb 붙인다. -> ex) 7+8 =15, 15%10-> 5이기에 일의자리 숫자만 뽑을 수 있음.
			carry = sum/10; // carry에는 +1 값을 넣는다. ex) sum= 15 -> 15/10은 1이기에 10이상 +1의 값만 뽑을 수 있게됨.
			
			i--; // 맨마지막 인덱스부터 시작하기에 --를 해서 왼쪽 인덱스로 이동한다.
			j--;
		}

		return sb.reverse().toString(); // 맨오른쪽 인덱스부터 더해서 붙였기에 reverse를 해줘야 원래대로 더한 값이 정상적으로 출력됨.

	}
}
```
